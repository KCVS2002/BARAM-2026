# 풍력발전량 영향 요소 이론 조사 종합 (2026-07-23)

모델·학습데이터에서 물러나 "이론적으로 무엇이 발전량을 결정하는가"를 5개 영역 병렬 조사한 결과.
각 영역 상세와 출처는 조사 에이전트 보고(대화 로그) 참조. 여기는 종합 + 모델 함의만.

## 0. 확정된 단지 사실 (피처 설계 기반)

- **구성**: 1단계 VESTAS 3.6MW×12기 (2020.9~11 상업운전) = group_1/2, 2단계 UNISON U136
  4.2MW×5기 (2022.11 준공) = group_3. 태백시 원동, 가덕산(1,078m) 능선 1,000~1,200m.
- **좌표**: 단지 중심 약 (37.285N, 128.959E). OSM에서 VESTAS 12기 좌표 확보 (배치 = 남쪽으로
  열린 말굽: 서쪽 다리 5기 주향 약 N340°~N15°E, 동쪽 다리 7기 약 N115°~150°E, 간격 250~440m
  = 1.8~3.3D 조밀). group_1↔서다리/group_2↔동다리 대응 가능성 (미확정).
- **컷아웃**: U136 공식 22 m/s (cut-in 3.0 / rated 11.3). VESTAS 기종 미확정 —
  V136류면 22.5, V117/V112류면 25 m/s. **학습 실측에서 역추정 필요.**
- **허브고도**: 2단계 117m 유력, 1단계 미확인 (~100m 내외 추정).
- **이용률**: 28~33% (국내 육상 최상위). 2025년 고장·출력제한 보도 없음.
- **인접 단지**: 매봉산(남 7km)·귀네미(북동 6km)·대명태백(북 3km). 하사미(코오롱, 4.4MW×4)는
  2026.4 준공이라 2025년 평가기간 중 미가동.
- **산식 = KPX 재생에너지 발전량 예측제도 그대로** (6%/8% 정산, 이용률 10% 필터, 용량 기준
  오차율; 풍력 4%/6% 강화는 2026.6 적용이라 2025년은 6%/8% 유효). 라벨은 송전단(소내·변압
  손실 제외) 계량 추정.
- **라벨 실효 상한** (직접 확인): g1 98.5%C / g2 98.9%C / g3 100.6%C(명판 초과!) — 연도 안정.
  단 현행 예측 최대 94.4%C라 상한 클리핑은 비문제 (확인 완료).

## 3. 실험 후보 랭킹 (전이 법칙 필터 적용)

티어 1 — 기존 데이터만, 물리 메커니즘 명확 (CV 신뢰 가능 클래스):
1. **밀도보정 유효풍속** v·(ρ/1.225)^(1/3) (ρ = p/(287T), p는 표고 근사): 무릎 이동의 직접 원인,
   연도 불변 물리. 주 풍속 피처들(ldaps_ws50max, gfs_ws100, ifs_ws925 등)에 적용한 변형 추가.
2. **능선 상대 풍향·Froude 세트**: U⊥ = |V·n̂| (두 다리 주향 N20°E/N140°E 각각),
   sin²(dir−주향), Fr = U⊥/(N·h) (N은 기존 t925·dT에서). 방향과 안정도의 물리 결합 —
   #66(안정도)의 성공 축을 방향 차원으로 확장.
3. **강풍 이력 피처**: 직전 3~6h 최대 예보 풍속(비대칭 롤링), 컷아웃 근접 지표.
   빈도 낮으나 밴드 손실 극대 구간. 학습 전 기종별 컷아웃 실측 역추정 진단 선행.

티어 2 — 기존 외부 데이터 재활용 (커버리지 확인 필요):
4. **사이클 간 spread**: OM previous_day1/2/3 차분 → 예보 변동성 피처. 커버리지가 2022부터면
   main 투입, 아니면 보류 (v39 불일치 함정).

티어 3 — 신규 수집 또는 재구조화 (정보축·대공사, 별도 판단):
5. LDAPS 격자 공간 통계 (문헌 최대 이득이나 수집 필요).
6. 착빙 다일 누적 (과거 관측 활용 — 합법이나 신규 수집).
7. 소스별 독립모델 스태킹 (파이프라인 재구조화).

기각 확인(조사로 종결): copula/램프 모듈/출력제한/소음/상한 클리핑(예측 94.4%C 최대라 비문제).
