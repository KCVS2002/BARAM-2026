## A. 실험 중 (v9 배치, 2026-07-12)

1. **(a) 고출력 가중 학습**: 샘플 가중 `w × (1+2·cf)`. FICR이 실제발전량 가중 정산이므로
   손실도 그 구조를 반영해야 정렬됨.
2. **(b) 최근성 가중**: 반감기 18개월 지수감쇠. 분포이동 완화 목적.
3. **(c) 램프·veer 피처**: 사이클 내 2/3h 차분, 6h 레인지, 연직 풍향 시어(100m↔850hPa),
   풍향 3h 변화량.
4. **(d) 단조 제약**: 주요 풍속·풍력밀도 피처에 monotone +1 (LightGBM). 외삽·이동 강건성.

## B. 후속 후보 (우선순위순)

1. **파워커브 프라이어 피처** (KMA 875hPa 완료 후): SCADA로 실측 단지 파워커브 적합 →
   `pc(ws875)` 를 피처로. GBM이 3차 증가+정격 포화 형태를 스스로 배우는 부담 제거.
   특히 고출력 적중률 개선 기대 (진단 1번 직결).
2. **2단계 모델**: NWP → SCADA 실측 풍속 회귀(1단) → 보정 풍속 피처로 발전량(2단).
   방법론 문서의 미구현 항목. NWP 풍속 편향의 명시적 제거.
3. **이종 알고리즘 앙상블**: CatBoost 퀀타일(+XGBoost) sister → 퀀타일 평균.
   오차 상관이 낮은 모델 결합은 v5(동종 시드)와 달리 실익 기대.
4. **리드타임 대응**: (i) lead_h × 풍속 상호작용 명시 피처, (ii) 의사결정 레이어에서
   리드타임별 스프레드 스케일 학습 (단, v7c 교훈 — 폭 조절은 신중).
5. **그룹별 잔차 보정**: 공유 모델 출력에 그룹별 소형 보정 모델 스태킹 (g2는 그룹별이
   근소 우위였음 — 로그 #4).
6. **의사결정 레이어 미세화**: 후보 그리드 61→201, a_bar 월별화. (기대 효과 소폭)
7. **cf^(1/3) 타깃 변환**: 저출력 구간 해상도 개선 실험. (리스크: 고출력 해상도 저하 —
   진단상 고출력이 중요하므로 후순위)

## C. 기각/종결된 방향 (재시도 금지 근거)

- 통계적 퀀타일 캘리브레이션·불확실성 기반 폭 조절 (calib, v7b, v7c):
  이 산식은 날카로운 분포를 보상. 3회 독립 실험 일관 결론.
- 동종 시드 앙상블 (v5): smooth 레이어와 효과 중복.
- 배깅 무작위성 제거 하이퍼파라미터 (v6): 분포이동 취약.
