작성일: 2026-07-11 · 상태: 초안

> **누수-안전 원칙 (전 소스 공통)**: 제공 데이터와 동일하게
> **D-1 09 KST(00 UTC) 초기화 사이클, 대상 D일 01시~D+1일 00시(예보시간 f016~f039)** 만 사용한다.
> 이보다 늦게 발표된 사이클을 쓰면 즉시 누수·실격. 수집한 모든 파일은 출처·수집시점·사이클·
> 라이선스·발표시각 근거를 아래 `external_data/README.md`에 기록한다(2차 평가 재현 의무).
>
> **대상 지점**: 터빈 중심 ≈ **37.28°N, 128.95°E** (강원 태백 가덕산). 주변 격자만 받으면 충분.

## ① 기상청 API허브 — LDAPS 원본 / 동네예보 (사용자 작업 필요)

제공된 LDAPS 컬럼의 원천. 더 많은 변수·연직레벨(하층/상층 바람, 안정도)을 보강할 수 있음.

**사용자가 할 일 (약 5분):**
1. https://apihub.kma.go.kr 접속 → 우측 상단 **회원가입**(무료). 이메일 인증.
2. 로그인 후 **마이페이지 → 인증키(API Key) 발급/확인**. 키 문자열을 복사.
3. 그 키를 아래 방식 중 하나로 Claude에게 전달:
   - 프로젝트 루트에 `.env` 파일 생성 후 `KMA_APIHUB_KEY=발급받은키` 한 줄 저장 (권장), 또는
   - 채팅으로 알려주기.
4. (선택) API허브에서 사용할 데이터 확인 — 예: **수치예보모델 → LDAPS(UM 국지)** GRIB, 또는
   **단기예보(동네예보) 과거자료**. 어떤 목록이 보이는지 알려주면 Claude가 맞는 엔드포인트를 고름.

> ⚠️ 키는 민감정보이므로 `.env`는 절대 제출/공유 파일에 포함하지 않음. Claude가 코드에 하드코딩하지 않고
> 환경변수로만 읽도록 작성.

**주의**: API허브의 LDAPS 아카이브 보관기간이 2022년까지 소급되는지는 키 발급 후 실제 조회로 확인해야 함
(안 되면 이 소스는 2025 test 추론용 실시간 보강으로만 사용, 학습기간은 제공 데이터로 커버).

## ② NOAA GFS 아카이브 (AWS S3, 퍼블릭 — Claude 수집 가능)

- **무엇**: 제공 GFS(9개 변수 그룹)보다 많은 변수·연직레벨을 전 기간(2021~) 제공. 라이선스 = 미국 정부
  **public domain**(무제한 사용).
- **버킷**: `s3://noaa-gfs-bdp-pds/` (자격증명 불필요).
- **권장 도구**: Python **Herbie** (`pip install herbie-data`) — 사이클·예보시간·변수·영역 subset 지원.

**누수-안전 수집 설정 (반드시 준수):**
```python
from herbie import Herbie
# D-1 00 UTC run, 예보시간 f016~f039 (= 대상 D일 01시~D+1일 00시 KST)
H = Herbie("2024-12-31 00:00", model="gfs", product="pgrb2.0p25", fxx=16)  # 예: fxx 16..39 루프
# subset: 터빈 주변만. 변수 예) 10m/80m/100m u·v, 2m T, mslp, gust, 하층운 등
ds = H.xarray(":(?:UGRD|VGRD|TMP|GUST|PRES):", remove_grib=True)
# 37.28N,128.95E 최근접 격자 몇 점만 추출해 CSV로 누적
```
- **용량 경고**: 변수·영역을 subset해도 3년치 매일 f016~f039(24스텝)이면 수천 요청. 시간이 걸림.
  → 먼저 **2024년 몇 달만 시범 수집 → 효용(CV 개선) 확인 후 전 기간 확대**.
- 저장: `external_data/gfs_noaa/gfs_YYYYMMDD_00z_fXXX.csv` 형태로 지점·변수만.

## ③ Open-Meteo — 과거예보 / 이전 런 (Claude 직접 수집)

- **무엇**: ECMWF-IFS, ICON, GFS 등 여러 모델의 과거 운영예보를 시간별로 제공 → **다중 NWP 앙상블**의
  ECMWF/ICON 확보 경로. 라이선스 **CC-BY 4.0**(상업적 이용·재배포 허용, 출처표기).
- **엔드포인트**:
  - Historical Forecast API: `https://historical-forecast-api.open-meteo.com/v1/forecast`
  - Previous Runs API (리드타임 고정): 변수에 `_previous_dayN` 접미사.
- **누수 검증 필요(R4)**: `_previous_day1`(24h 전 예측)이 우리 기준(D-1 13 KST 발표) 이전인지
  모델 사이클 타이밍을 개별 확인. 애매하면 **`_previous_day2`(48h 전)** 사용 → 안전하지만 정확도↓.
- **예시 요청** (37.28N,128.95E, 시간별 100m 바람, day1 리드타임):
  ```
  GET /v1/forecast?latitude=37.28&longitude=128.95
      &hourly=wind_speed_100m_previous_day1,wind_direction_100m_previous_day1,temperature_2m_previous_day1
      &start_date=2024-01-01&end_date=2024-12-31&timezone=Asia/Seoul&models=ecmwf_ifs025
  ```
- **커버리지**: 대부분 모델 2024-01~ → 학습기간 중 2024만. 2025 test 구간은 전부 커버되므로
  **test 추론용 보강**으로는 특히 유효.
- 저장: `external_data/openmeteo/{model}_{leadtime}.csv`.
