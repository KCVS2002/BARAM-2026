# v17 계획: GEFS 실물 멤버 시나리오 원자 (수집 완료 후 실행)

## 배경
- 수집 중: `scripts/collect_gefs_members.py` → `external_data/gefs/gefs_members_2024_2025.csv`
  - 로그: `logs/collect_gefs_members.log`, 백그라운드 task bdjcmi8tr
  - 내용: GEFS c00 + p01,p03,...,p29 (16멤버), 10m u/v, f15~39 3h 간격, 9격자, 2024~2025
- v16(스프레드 요약 z-시나리오)은 기각됐지만, **기각 사유는 "균일 배율 = 폭 조절"이라는 점**.
  실물 멤버는 시간별로 상관된 진짜 대안 흐름(시나리오)이므로 별개 가설.

## 실행 절차
1. 수집 검증: 멤버 수 16개, 2024~2025 커버리지(슬롯별 결측률), 값 범위 sanity check.
2. 멤버별 풍속비 `f_m(t) = ws_member(t) / ws_ensmean(t)` 계산 (3h → 1h 보간, clip 0.4~1.8).
   - ws_ensmean은 멤버 평균으로 직접 계산 (gefs_stats의 avg와 교차검증).
3. v15/v16과 동일한 골격 (`scripts/train_v16_gefs.py` 복사 후 수정):
   - 학습 불변. 예측 시점에 풍속류 피처 × f_m, CUBE_COLS × f_m³ 치환.
   - 멤버당 소수 분위(Q_SCEN=[0.1,0.3,0.5,0.7,0.9]) 예측 → 16멤버 × 5분위 = 80 원자.
   - GBM 중앙값으로 재정렬(shift) 후 gbm(150) + anen(150) + scen(80×2배=160)에 결합.
   - 기준: sub_009 구성 CV 0.6470. 6fold(2024 2개월×6) fold별 일관성 확인.
4. 판정: 3단계(채택/보류/기각) + 원인 분석. v16과의 차이(실물 흐름 vs 균일 배율)가
   결과에 반영됐는지 반드시 해석할 것.

## 주의
- 2022~2023 학습기간 멤버는 없음 → 예측시점 치환 방식이므로 학습 커버리지 문제 없음.
- CV는 2024 검증이므로 GEFS 멤버는 2024 구간만 있으면 CV 가능. 2025는 제출 시 필요.
- NOAA 2022-11-30 00Z 손상 이슈와 동일한 결측일이 있으면 f_m=1 (시나리오 없음) 처리.
